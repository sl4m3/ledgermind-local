# Миграция v3 → v4

## Стратегия
- v3 остаётся до сквозной проверки.
- Временная команда: `ledgermind-v4`.
- После проверки переключить на `ledgermind` и удалить старые точки входа.

## Хранилище
- Источник: старый `storage_path` + `semantic/semantic_meta.db`.
- Назначение: временная база, затем `~/.ledgermind/local/ledgermind.db`.
- Старый векторный индекс не переносится.
